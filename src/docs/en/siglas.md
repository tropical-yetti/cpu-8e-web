# Abbreviations

The same explanations show up as a caption when you hover (or focus with the keyboard) each abbreviation on the simulator panel, or tap it on a phone.

{{siglas}}

The original panel uses Portuguese abbreviations. In the Portuguese interface, ALU, CU, ID, IB, AB and DB show up as **ULA**, **UC**, **DI**, **BI**, **BE** and **BD**.
